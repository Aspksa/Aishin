# Aishin

Aishin — локальный проект личной AI-помощницы Айшин (Айши).

## Версия
`0.0.2` — живое постоянное ядро.

## Что уже заложено
- ядро на Python/FastAPI;
- локальная SQLite-база данных;
- веб-интерфейс;
- Windows-запуск через `Aishin.bat`;
- модуль **Aishin Kitsune** — личная помощница;
- модуль **Личный кабинет**;
- модуль **Мобильное приложение**;
- модуль **Рабочее пространство**;
- нижний пункт **Система обновления** с обновлением через GitHub;
- отдельное runtime-ядро личности Айшин;
- базовый слой памяти;
- логотип Айшин, встроенный в интерфейс.

## Запуск
На Windows запустите `Aishin.bat`.

Первый запуск создаст локальное Python-окружение, установит зависимости, проверит обновления и откроет `http://127.0.0.1:8765`.

## Архитектурный принцип
Личность Айшин не должна зависеть от конкретной LLM. Её характер, правила, память и принципы хранятся в собственном ядре проекта. AI-модель является сменным когнитивным двигателем поверх этого ядра.

## Следующий этап
Подключение сменного AI-движка через единый adapter, затем семантической памяти, графа связей и проактивных задач.
