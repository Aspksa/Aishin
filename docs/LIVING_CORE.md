# Живое ядро Айшин

Версия фундамента: 0.0.2.

Под словом «живая» в архитектуре проекта понимается не биологическое сознание, а непрерывная программная личность: Айшин сохраняет идентичность, историю, состояние и память между запросами и не зависит от конкретной LLM.

## Контур

`восприятие -> определение намерения -> извлечение памяти -> формирование контекста -> мышление -> ответ -> запись события -> обновление состояния`

## Постоянные слои

1. **Personality / Soul** — полный `AISHIN_PERSONALITY_PROFILE.json`. Это каноническая личность и правила поведения.
2. **Runtime State** — текущий статус, фокус, активность, условное настроение, внимание, счётчик взаимодействий и heartbeat.
3. **Long-term Memory** — память с областью (`scope`), типом, уверенностью, важностью, источником и тегами.
4. **Conversation History** — отдельный журнал сообщений.
5. **Event Stream** — журнал событий: запуск, входящие сообщения, сохранение памяти, ответы, обновления системы.
6. **Cognition** — слой маршрутизации и сборки контекста перед обращением к AI-модели.
7. **Heartbeat** — фоновый пульс процесса. Он показывает, что runtime запущен, и даёт будущим автономным задачам точку исполнения.

## Важное правило

LLM является сменным когнитивным двигателем. Личность, память, история и правила Айшин не должны исчезать при смене Ollama, облачной модели или другого провайдера.
